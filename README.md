# EMSH

Extensible Modular SHell - POSIX-compliant and easily extensible with Lua modules.

> [!NOTE]  
> EMSH is early in development and is still missing most features.  
> It is not currently recommended for general usage.

> [!NOTE]  
> Check the documentation in [emsh.md](docs/manual/emsh.md) for more information about the project  
> Check [checklist.md](checklist.md) for current implementation status.
